## 2. Threat Hunting

Performed hands-on threat hunting using Wazuh and collected security telemetry.

Investigated events including:

- Successful sudo activity
- PAM login sessions
- Authentication activity
- File changes
- VirusTotal integration
- File/hash reputation analysis
- Threat intelligence enrichment
- Security alerts
- Suricata network alerts
  

### Example Investigation

A Wazuh Threat Hunting dashboard initially returned **0 hits**.

Investigation identified an incorrect saved time field:

`timestamp`

The actual mapped date field was:

`@timestamp`

After correcting the Wazuh index pattern configuration, Threat Hunting successfully displayed security events, including authentication and privilege-related activity.

**Result:** Threat Hunting functionality was restored and events became visible in the dashboard.
